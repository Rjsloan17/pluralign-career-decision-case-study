# Pluralign — Career Decision Product Case Study

A public-safe product case study demonstrating problem framing, MVP scope, beta design, product tradeoffs, and founder product leadership.

## Public disclosure boundary

This repository intentionally excludes participant data, credentials, private source code, and internal implementation details.

## Publish

1. Create a new public repository named `pluralign-career-decision-case-study`.
2. Upload these files as the repository's first commit.
3. In **Settings → Pages**, deploy from the `main` branch root.
4. Confirm the live URL before publishing the Pluralign site.
